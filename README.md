# FinGuard AI

AI-Powered Smart Banking & Fraud Detection Platform

## Overview
FinGuard AI is a full-stack intelligent banking platform designed to provide secure digital transactions, fraud detection, AI-powered financial insights, and real-time analytics.

The platform combines machine learning-inspired fraud analysis with modern financial dashboarding to help users manage transactions securely and efficiently.

---

## Features

### User Features
- JWT Authentication
- Secure Login & Registration
- Wallet Management
- Transaction History
- Beneficiary Management
- Spending Analytics
- Financial Health Insights
- AI Financial Assistant
- Spending Prediction Engine
- Fraud Risk Detection

### Admin Features
- Fraud Monitoring Dashboard
- User Management
- Transaction Monitoring
- Activity Logs
- Fraud Alert System
- Risk Score Analysis
